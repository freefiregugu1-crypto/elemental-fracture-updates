# Elemental Fracture — atualizacoes

Este repositorio distribui somente pacotes compilados de conteudo do jogo Android. As versoes publicadas ficam em **Releases**.

O aplicativo verifica o manifesto no boot e pede confirmacao antes de baixar, mostrando tamanho, progresso e velocidade. Cada pacote tem verificacao de integridade e compatibilidade com o APK.

Codigo-fonte, credenciais e saves pessoais nao fazem parte deste repositorio. Alteracoes de codigo C# exigem novo APK.
